# CogniPlan Icons

This folder stores all icons used across the CogniPlan project.

## Current Files

| File | Description |
|------|-------------|
| `icon-set-preview.png` | Full icon sheet preview (AI-generated reference) |

## Planned Individual Icons

Once individual SVG/PNG icons are added, they will follow this naming convention:

| Filename | Used For |
|----------|----------|
| `icon-logo.svg` | App brand / lightning bolt |
| `icon-habit-done.svg` | Habit completion checkmark |
| `icon-streak.svg` | Flame / streak counter |
| `icon-matrix.svg` | Habit calendar grid |
| `icon-progress.svg` | Doughnut ring / analytics |
| `icon-ai.svg` | AI Co-Pilot chat button |
| `icon-todo.svg` | Todo checklist |
| `icon-profile.svg` | User profile badge |
| `icon-add.svg` | Add new habit / todo |
| `icon-delete.svg` | Delete / trash bin |
| `icon-logout.svg` | Logout arrow |
| `icon-notification.svg` | Bell / alerts |

## Usage in HTML

```html
<img src="./icons/icon-streak.svg" alt="Streak" width="24" height="24" />
```

## Usage in CSS

```css
background-image: url('./icons/icon-logo.svg');
```

## Notes
- Prefer SVG format for icons (scalable, small file size)
- Use PNG only for complex multi-color icons
- Keep icon size consistent: 24×24px for UI, 48×48px for larger displays
